# Install Dhan-OM v1.9 (do this on the phone)

GitHub **never** gives you an `.apk` from Actions. It gives a **ZIP**.
Installing the ZIP is why you see **App not installed**.

1. Open this green run: https://github.com/ecovia-2026/Dhanom/actions
2. Open the latest **Android CI - Build APK** (green).
3. Download **`DhanomAI-Finance-debug-apk`** only. Skip `merged-apks`.
4. In **Files / My Files / Downloads**, find `DhanomAI-Finance-debug-apk.zip`.
5. **Extract / Unzip** it. Open the folder. Tap **`app-debug.apk`**.
6. Allow **Install unknown apps** for **Files** (not only Chrome).
7. Play Store → profile → **Play Protect** → turn **Scan apps** OFF → install → you can turn it back on.
8. Xiaomi/Redmi/POCO: Settings → Privacy → Special permissions → Install unknown apps → Files → Allow.  
   Also try Settings → Additional settings → Developer options → turn **MIUI optimization** off.

v1.9 is a new app (`com.dhanom.ai`). You will get a new icon. Delete any old Dhan-OM after.
