# Dhan-OM · On-Device Gemma Brain — Setup, Troubleshooting & Monthly Update Guide

This file is the single source of truth for the **on-device Gemma brain** used
by Dhan-OM. Keep it updated whenever the model or runtime changes.

## What the brain is

- **Runtime:** Google **LiteRT-LM** (the current on-device LLM runtime).
  Gradle: `com.google.ai.edge.litertlm:litertlm-android:0.16.1`
  (MediaPipe `tasks-genai` is deprecated/maintenance-only — do not reintroduce it.)
- **Model:** **Gemma 4 E4B** (~4.5B effective params), LiteRT format.
  - File: `gemma-4-E4B-it.litertlm` (~3.66 GB, CPU)
  - Official public URL:
    `https://huggingface.co/litert-community/gemma-4-E4B-it-litert-lm/resolve/main/gemma-4-E4B-it.litertlm`
  - GPU variant (optional, needs OpenCL on device):
    `gemma-4-E4B-it-gpu.litertlm` (~2.97 GB, same repo)
- **Storage:** downloaded to the app's internal storage
  (`filesDir/models/gemma-4-E4B-it.litertlm`). Delete it any time from
  Profile → AI Brain → Delete model.
- **RAM:** needs ~8 GB free RAM. Your 16 GB device is well within limits.

## First-run flow

1. App opens → welcome voice + a prompt: *"Install the on-device Gemma brain?"*
2. Tap **Download now** → ~3.66 GB download with a live progress bar.
3. When done, the brain auto-activates. Every chat answer is then generated by
   the on-device Gemma model — fully offline, no API key.

If you skip the prompt, enable it later: **Profile → AI Brain → Gemma 4 E4B → Download model**.

## If the download fails

| Symptom | Cause | Fix |
|---|---|---|
| HTTP 401 / 403 | The HuggingFace repo requires login (rare for `litert-community`) | Accept the Gemma license on huggingface.co once, or use a mirror URL |
| Slow / stalls on mobile data | 3.66 GB over a flaky connection | Use Wi-Fi; the download resumes from scratch |
| "downloaded 0 bytes" | Interrupted transfer | Retry from Profile → Download model |
| Out of space | 3.66 GB + working space needed | Free up ~8 GB, then retry |

You can also paste **any other `.litertlm` model URL** in
Profile → AI Brain → *Model download URL* (e.g. Gemma 4 E2B, Gemma 3n, or a
fine-tuned finance model) — the app treats it the same way.

## If the brain answers slowly or falls back to canned replies

- The app **always falls back to the offline NLU brain** when the model is
  missing or errors out — that is by design (it must never hard-crash).
- Check **Profile → AI Brain → Model status**: it must say `Ready · <size> MB`.
- If it says `Not installed`, download the model.
- First answer after cold start takes a few seconds (model loads into memory).
  Subsequent answers are faster.
- The model runs on **CPU** by default. For faster output on a GPU-capable
  device, download the `-gpu.litertlm` variant and ensure OpenCL is present.

## Self-heal & crash log

Dhan-OM installs a global crash handler: any crash is written to
`filesDir/crash-log.txt`, and the app restarts itself (guarded against restart
loops). View/clear it in **Profile → Self-heal & Crash Log**. If a crash
repeats, share that log — it contains the exact exception + stack.

## Monthly update cadence

Run this checklist monthly (or on any major upgrade):

1. **Bump the LiteRT-LM dependency** — check Google Maven for the latest
   `com.google.ai.edge.litertlm:litertlm-android` version and update
   `gradle/libs.versions.toml` → `litertLmAndroid`.
2. **Re-check the model URL** in `AppPrefs.kt` (`DEFAULT_GEMMA_MODEL_URL`) —
   newer Gemma releases (E4B-QAT, next-gen E2B/E4B) may be smaller/faster.
3. **Update `GemmaBrainEngine.SYSTEM_PROMPT`** with any new finance features
   (tax rules, new categories, voice/multimodal).
4. **Rebuild & smoke-test:** install the APK, chat with the brain on device,
   verify Profile → Model status says Ready.
5. **Update this file** with anything you changed.

## Adding multimodal (image / audio)

Gemma 4 E2B/E4B support vision + audio. To enable later, extend
`GemmaBrainEngine` to call `sendMessage(Contents.of(Content.ImageFile(...), Content.Text(...)))`
and add `visionBackend` / `audioBackend` to `EngineConfig` (see Google's
LiteRT-LM Android guide).
